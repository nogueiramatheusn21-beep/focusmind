# FocusMind

Sistema desktop de organização de estudos desenvolvido em Java.

---

## Tecnologias utilizadas

- Java Swing
- MySQL
- JFreeChart
- OpenPDF
- JCalendar
- Launch4j
- Inno Setup

---

## Funcionalidades

- Login de usuários
- Cadastro de tarefas
- Dashboard com gráficos
- Exportação em PDF
- Sistema desktop com instalador Windows
- Interface moderna
- Integração com MySQL

## Como executar

### Executar pelo EXE

Abra:

```text
SistemaEstudos.exe
```

### Executar pelo Java

```bash
java -cp "SistemaEstudos.jar;libs/*" src.Main
```
