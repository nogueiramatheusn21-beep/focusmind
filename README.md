# FocusMind

Sistema desktop de organização de estudos desenvolvido em Java.

## Tecnologias utilizadas

- Java Swing
- MySQL
- JFreeChart
- OpenPDF
- JCalendar

## Funcionalidades

- Login de usuários
- Cadastro de tarefas
- Dashboard com gráficos
- Exportação em PDF
- Sistema desktop com instalador Windows
